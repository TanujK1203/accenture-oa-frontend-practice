# Y01 — Dynamic Change Class

## How to Attempt?

This question was reported from a recent Accenture OA. You are given a partially complete page with an HTML, CSS and JavaScript template already in place. Modify the template as per the objectives below. Nothing has to be built from scratch.

## Objectives

- Add a paragraph with the id `p` and the class `p` inside the container, above the button. Its text must be exactly `This a paragraph`.
- Create a class named `change` in style.css. When the paragraph has this class, its border must be `dashed`.
- When the button has the `change` class, its width must be `120px`.
- Clicking the button must add the `change` class to both the paragraph and the button. The class must be added dynamically with JavaScript, not written in the HTML.

## Constraints

- Do not remove or rename the existing ids and class names.
- Before the button is clicked, the paragraph's border must stay solid and the button must stay `80px` wide.
- Copy the paragraph text exactly as given, including its wording.
