# Q09 — Temperature Converter

## How to Attempt?

You are tasked with completing a Celsius to Fahrenheit converter. The project is partially complete and contains 1 bug in the JavaScript. Implement the remaining HTML, CSS and JavaScript requirements and fix the bug so decimal temperatures convert correctly.

## Objectives

- Change the input so it only accepts numbers.
- Clicking Convert must show the result in `#result` in the format `<value> °F`, rounded to 1 decimal place. For example, `25` gives `77.0 °F` and `36.6` gives `97.9 °F`.
- If the input is empty, `#result` must show `Please enter a valid number`.
- If the temperature is `30` °C or more, `#result` must have the class `hot`; for lower temperatures the class must be removed. A `#result` with the class `hot` must have the text color `#e63946`.
- Change the font size of `#result` to `24px`.

## Constraints

- Do not remove or rename the existing ids and class names.
- Use the formula F = C × 9 / 5 + 32.
