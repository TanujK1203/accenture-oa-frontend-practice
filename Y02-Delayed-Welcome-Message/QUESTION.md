# Y02 — Delayed Welcome Message

## How to Attempt?

This question was reported by a candidate on Reddit. You are given a working template for a welcome board. Make the small HTML, CSS and JavaScript changes listed below. The JavaScript logic is already written; you only need to adjust it.

## Objectives

- Change the background color of the page (`body`) to `#e6f2ff`.
- Add the id `message` to the existing `<p>` tag that has the class `message`.
- The welcome message must appear 5 seconds after the button is clicked. It currently uses 1 second (1000 ms).

## Constraints

- Do not remove or rename the existing class names.
- Do not change the welcome text written in script.js.
- Do not add a second timer. Change the existing one.
