# Q08 — Student Result Table

## How to Attempt?

You are tasked with completing a Student Result table. The project is partially complete and contains 1 bug in the JavaScript. Implement the remaining HTML, CSS and JavaScript requirements and fix the bug so each student gets the correct result.

## Objectives

- Add a new row for `Rohan` with `40` marks as the last row of the table body. Use the same cells and classes as the other rows.
- The table must not show double borders between cells.
- The header cells (`th`) must have the background color `#2d3e50` and the text color `#ffffff`.
- Clicking Check Results must fill each Result cell with `Pass` (40 marks or more) or `Fail` (below 40).
- Clicking Check Results must also add the class `fail` to every failing row (`tr`), and a row with the class `fail` must have the background color `#ffe5e5`.

## Constraints

- Do not remove or rename the existing ids and class names.
- Do not change the marks of the existing students.
