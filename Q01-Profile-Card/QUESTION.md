# Q01 — Profile Card

## How to Attempt?

You are tasked with completing a Profile Card interface. The project is partially complete and contains 2 bugs, one in the CSS and one in the JavaScript. Implement the remaining HTML, CSS and JavaScript requirements and fix the bugs so the card works as described.

## Objectives

- Add a paragraph with the class `role` directly below the name. Its text must be `Frontend Developer`.
- Add an `alt` attribute with the value `Riya Sharma` to the avatar image.
- Make the avatar image a perfect circle.
- Clicking the Follow button must toggle the class `following` on it and switch its text between `Follow` and `Following`.
- While the button has the class `following`, its background color must be `#28a745`.

## Constraints

- Do not remove or rename the existing ids and class names in the HTML.
- Do not change the image `src`.
