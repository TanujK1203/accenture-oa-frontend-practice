# Q02 — Login Form

## How to Attempt?

You are tasked with completing a Login Form. The project is partially complete and contains 3 bugs spread across the HTML and JavaScript. Implement the remaining requirements and fix the bugs so the form behaves as described.

## Objectives

- The password field must hide the characters typed into it.
- Clicking the `Password` label must focus the password input.
- Add the placeholder `Enter username` to the username input.
- When an input with the class `input` is focused, its border color must be `#0073e6`.
- Submitting the form must not reload the page. It must show `Welcome, <username>!` in `#msg` (ignoring leading and trailing spaces), or `Please enter your username` if the username is empty.

## Constraints

- Do not remove or rename the existing ids and class names.
- Keep the Login button as a submit button inside the form.
