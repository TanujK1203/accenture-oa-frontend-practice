# Q05 — Read More Toggle

## How to Attempt?

You are tasked with completing a blog post preview with a Read More button. The project is partially complete and contains 2 bugs, one in the CSS and one in the JavaScript. Implement the remaining requirements and fix the bugs so the extra text can be shown and hidden.

## Objectives

- Add a paragraph with the id `more` and the class `more` right after the intro paragraph. Its text must be `It also runs on servers, mobile apps and even smart TVs.`
- The `#more` paragraph must be hidden when the page loads.
- When `#more` also has the class `show`, it must be visible with `display: block`.
- Clicking the button must toggle the class `show` on `#more` and switch the button text between `Read More` and `Read Less`.
- Change the background color of the button to `#6c63ff`.

## Constraints

- Do not remove or rename the existing ids and class names.
- Do not use inline styles (the `style` attribute or `element.style`) to show or hide the paragraph.
