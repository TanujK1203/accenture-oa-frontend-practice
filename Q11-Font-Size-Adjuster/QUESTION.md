# Q11 — Font Size Adjuster

## How to Attempt?

You are tasked with completing a reading page with A- / A+ font size controls. The project is partially complete and contains 1 bug in the JavaScript. Implement the remaining HTML, CSS and JavaScript requirements and fix the bug so the text size actually changes.

## Objectives

- Add a Reset button with the id `resetBtn`, the class `size-btn` and the text `Reset` inside the toolbar, after the A+ button. Clicking it must set the font size back to `16px`.
- Clicking A+ or A- must change the article's font size by `2px` and update `#sizeLabel` (for example `18px`).
- The font size must never go above `24px` or below `12px`.
- Center `.reader` horizontally on the page and give it a maximum width of `600px`.
- Change the line height of `.article` to `1.6`.

## Constraints

- Do not remove or rename the existing ids and class names.
- Keep the article's starting font size at `16px`.
