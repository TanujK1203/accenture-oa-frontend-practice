# Q12 — Navigation Bar

## How to Attempt?

You are tasked with completing a website Navigation Bar. The project is partially complete and contains 1 bug in the JavaScript. Implement the remaining HTML, CSS and JavaScript requirements and fix the bug so the active link is highlighted correctly.

## Objectives

- Add a fourth link after Services with the text `Contact`, `href="#contact"` and the class `nav-link`.
- Make `.navbar` a flex container that spreads the links out with `justify-content: space-between`.
- When a link is hovered, its background color must be `#374151`.
- Clicking a link must give only that link the class `active`.
- Clicking a link must change the text of `#pageTitle` to the text of that link.

## Constraints

- Do not remove or rename the existing ids and class names.
- Keep the links as `<a>` tags inside the `<nav>`.
