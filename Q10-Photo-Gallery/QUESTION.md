# Q10 — Photo Gallery

## How to Attempt?

You are tasked with completing a Photo Gallery where clicking a thumbnail shows it as the main photo. The project is partially complete and contains 1 bug in the JavaScript. Implement the remaining HTML, CSS and JavaScript requirements and fix the bug so the thumbnails respond to clicks.

## Objectives

- Add a fourth thumbnail after the third one: an `img` with the class `thumb`, the src `https://picsum.photos/id/40/480/300` and the alt `Photo 4`.
- Show the thumbnails in a single row with a gap of exactly `10px` between them.
- The thumbnail with the class `active` must have the border color `#ff6b00`.
- Clicking a thumbnail must show the same image in `#mainImage` (same `src` and `alt`) and set the text of `#caption` to the thumbnail's `alt`.
- After a click, only the clicked thumbnail must have the class `active`.

## Constraints

- Do not remove or rename the existing ids and class names.
- Keep the thumbnails as `<img>` tags.
